# IoT Security System

A proof of concept (PoC) for a global IoT security system with anti-theft alarms and security cameras, built on AWS.

## Overview
This project simulates a security system with IoT sensors (motion, door/window) and cameras, using AWS services for event processing, storage, and monitoring. Key features:
- **Microservice**: Java (Spring Boot) microservice (`device-service`) deployed on Amazon EKS using Helm, consuming Kafka events and storing in DynamoDB.
- **Lambdas**: Python functions (`alert-processor`, `image-processor`) for real-time alerts (SNS) and image analysis (Rekognition).
- **Infrastructure**: Defined with Terraform/Terragrunt, including AWS IoT Core, MSK (Kafka), SNS, SQS, DynamoDB, S3, EKS, Lambda, CloudWatch, Grafana, and QuickSight (optional).
- **CI/CD**: GitHub Actions pipeline with build, test, SonarQube, OWASP, Trivy, and Slack notifications.
- **Simulation**: Scripts to simulate sensors and cameras sending events to IoT Core.

## Prerequisites
- Python 3.9+
- Java 17
- Maven 3.8+
- Terraform 1.5+
- Terragrunt 0.48.0+
- Helm 3.14.0+
- Docker
- LocalStack for AWS simulation
- Dependencies: `paho-mqtt`, `boto3`, `Pillow`

## Setup Instructions
1. **Clone Repository**:
   ```bash
   git clone https://github.com/anmobor2/iot-security-system.git
   cd iot-security-system
   git checkout master
   ```

2. **Install Dependencies**:
   ```bash
   pip install paho-mqtt boto3 Pillow
   cd microservices/device-service
   mvn clean install
   ```

3. **Start LocalStack**:
   ```bash
   ./scripts/localstack_setup.sh
   ```

4. **Deploy Infrastructure**:
   ```bash
   cd infrastructure/terragrunt/dev
   terragrunt init
   terragrunt apply
   ```

5. **Run CI/CD Pipeline**:
   - Push to `master` to trigger `.github/workflows/ci-cd.yml`.
   - Verify deployment in EKS (namespace `iot-security`).

6. **Simulate Devices**:
   ```bash
   python scripts/simulate-sensor.py
   python scripts/simulate-camera.py
   ```

7. **Monitor**:
   - Access CloudWatch at `http://localhost:4566` for metrics and logs.
   - View Grafana dashboard at `http://localhost:3000`.
